## Models & datasets

- Embeddings: `sentence-transformers/all-MiniLM-L6-v2` (Apache-2.0, public).
- LLM: Anthropic Claude (used via official SDK, model invoked is in `.env`).
- No scraped or private data. All company data is generated by
  `data/generate_synthetic.py` with a fixed seed.

## Optional / off-by-default

- `data/github_import.py` (optional, **off by default**) imports only public
  GitHub repositories and only when explicitly enabled by env flag. If unused,
  delete the file.

## Assets

- No third-party images, fonts, or icons are vendored in the repo. Web UI uses
  system fonts only.
